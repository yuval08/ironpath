# Ironpath 1.0.1

- Adds nine strength-training movements to the exercise library, with instructions,
  equipment/load types, substitutions, and clearly labeled YouTube search links.
- Accepts `assisted-pull-up` and `flat-dumbbell-bench-press` as import aliases for
  the existing band-assisted pull-up and flat dumbbell press. All references,
  including key lifts, normalize to the canonical IDs to preserve progression history.
- Fixes import compatibility with the Phase 3 Strength Foundation ten-week file;
  its rest times, supersets, phases, bands, and load increments remain intact.
- Shows the app version alongside the build timestamp in Settings.

Update the installed PWA using **A new version is ready → Update**, then import
from **Settings → Your plans → Import plan from JSON**. The original Phase 3 file
can be used unchanged. Existing plans and workout history are retained.

See [supported IDs](../exercise-ids.md) and [JSON format](../plan-import.md).
