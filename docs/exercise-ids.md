# Supported exercise IDs — 1.0.1

Use these exact IDs in plan JSON `exercise`, `alternatives`, `warmUp.exerciseId`,
and `keyLifts` references. Display names are not identifiers.

## Accepted import aliases

| Input                       | Stored canonical ID     |
| --------------------------- | ----------------------- |
| `assisted-pull-up`          | `band-assisted-pull-up` |
| `flat-dumbbell-bench-press` | `flat-dumbbell-press`   |

These aliases normalize during import so progression, videos, and history use the
same movement as existing plans. `assisted-pull-up` means **band assistance** here;
assistance-machine counterweights are a different input model.

## Canonical library

New in 1.0.1: incline barbell bench press, underhand lat pulldown, bent-over barbell
row, dumbbell biceps curl, triceps pushdown (bar/handle), cable chest fly, shoulder
six-ways, dumbbell hammer curl, and overhead cable triceps extension.
